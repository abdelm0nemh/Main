# Sol d'Amore — Pink October TikTok videos

Three animated versions of the Pink October story designs. Each one is 1080×1920 (9:16), 30 fps, 12 s long, H.264 with a silent AAC track.

| File | Design | What moves |
|---|---|---|
| `videos/sol-damore-pink-october-1-we-stand-with.mp4` | 4-panel grid | Opens with a focus pull and a slow camera pull-back. The logo writes on, "FOR EVERY WOMAN" tracks in and "WE STAND WITH" rises word by word. Then the promo code builds, the footer fades up, a light sweeps along the ribbon and the code glows. |
| `videos/sol-damore-pink-october-2-we-care-about.mp4` | Burgundy layout | The ribbons glide in from the corners and keep drifting gently, with a satin sheen. The logo writes on and "WOMAN" and "ABOUT" rise letter by letter. The photo opens like a curtain with a slow zoom-out. The promo lines draw outward and "PINK" tracks in and glows. |
| `videos/sol-damore-pink-october-3-for-me.mp4` | Frosted-glass panel | Opens with a focus pull and a pull-back. "FOR ME" lands letter by letter from soft focus and the promo pill pops in. Light glides across the glass, the ribbon sheens and the code glows. |

The last frame of each video matches the original design.

## How it was made
The designs were split into layers in code: a clean background, plus separate text, logo, ribbon, photo and pill layers. Each layer is then animated on its own, so the type and logo stay pixel-sharp (nothing is regenerated by AI).

```
cd source
pip install numpy pillow opencv-python-headless   # ffmpeg is also required
# convert images/N.webp -> srcN.png (RGBA PNG), then:
python3 an2.py && python3 ex2.py && python3 ex1.py && python3 ex3.py
mkdir -p l1 l2 l3 && python3 v1.py ../videos/1.mp4  # same for v2.py and v3.py
```
